## 3. 🚨 CRITIQUE — à fixer avant exposition Internet

### C1. Aucun endpoint API n'est authentifié en mode local
**Fichier** : `src/main.py:43-45`, `src/core/cf_access.py:128-130`

`CloudflareAccessMiddleware` est **un no-op si `cf_access_team_domain` ou `cf_access_audience` sont vides** (défaut local). Tous les `/v1/*` (incluant `/ai/ask`, `/oauth/status`, `/photos/sync`, `/osint/*`, `/finance/*`, `/drive/wipe`) sont ouverts si le port 8000 est exposé (DuckDNS, port forward, Wi-Fi public). Quelqu'un peut vider la DB, lire `oauth_tokens`, déclencher Sherlock arbitraire.

**Fix** : refuser le startup si `app_env=production` sans CF Access OU ajouter un token statique en header pour le dev.

### C2. Secrets en clair sur Google Drive
**Fichier** : `hub-deploy/.env` (lignes 24, 37, 40)

```
DUCKDNS_TOKEN=1471bee3-e41b-4ef1-93f9-53aa9dcf5e8f
GOOGLE_OAUTH_CLIENT_SECRET=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
RESTIC_PASSWORD=MarcoPolo833!
```

`.gitignore` les protège côté Git, **mais le projet vit dans `G:\Mon disque\…` qui synchronise vers Google Drive Cloud**. Les secrets sont uploadés vers Google, accessible si compte compromis.

**Fix immédiat** :
1. Rotation des 3 secrets (DuckDNS regen, Google OAuth client_secret regen, Restic re-key)
2. Déplacer `.env` hors de Drive (ex: `C:\Users\dessin14\.hub-secrets\.env`) avec symlink
3. OU activer le vault age+sops déjà documenté (ADR-0006) mais jamais utilisé

### C3. SSRF + token leak via `enrich_gps` / `photo_thumbnail`
**Fichier** : `src/api/v1/photos.py:317`, `:367`, `src/services/photo_gps.py:48-52`

`Photo.base_url` lu depuis DB sans validation de domaine. Si une vulnérabilité ailleurs (ou requête API mal validée) permet d'écrire un `base_url` arbitraire, le serveur enverra le **Bearer token Google** à un domaine attaquant.

**Fix** : valider `base_url.startswith("https://lh3.googleusercontent.com/")` avant chaque GET.

### C4. Pas de limite de taille → DoS RAM via `download_photo_bytes`
**Fichier** : `src/services/photo_gps.py:40-52`

`r.content` charge **toute** la photo en RAM (5–15MB original, +pour 4K vidéos). `enrich_gps` boucle sans rate limit. Couplé à C1 → OOM trivial.

**Fix** : `httpx stream=True` + lire par chunks + `max_bytes=50_000_000`.

### C5. Direct external API calls depuis le frontend
**Fichier** : `components/password-checker.tsx:21,47`, `bulk-password-checker.tsx:38,67`, `breaches-analysis.tsx:38`

Le frontend appelle directement `api.pwnedpasswords.com` / `haveibeenpwned.com`. Viole la règle CLAUDE.md *"Ne JAMAIS appeler une API externe côté frontend"*. K-anonymity rend ça privacy-safe, mais c'est une dépendance externe visible dans DevTools.

**Fix** : proxy via endpoint hub-core `/v1/security/hibp-check`.

### C6. `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` exposé dans le bundle JS
**Fichier** : `components/google-location-map.tsx:35`

Toute env var `NEXT_PUBLIC_*` est dans le bundle. Si la clé n'a pas de restriction HTTP referrer, abus = facturation Google.

**Fix** : vérifier que les restrictions referrer sont actives dans Google Cloud Console.

## 4. 🟠 HAUT — bugs probables ou trous de sécurité importants

### H1. Validateur SQL contournable
**Fichier** : `src/api/v1/ai.py:218-246`

- Commentaires SQL `--` ou `/* */` non strippés avant vérif.
- `WITH RECURSIVE foo AS` raté par regex (`\bWITH\s+(\w+)\s+AS\b` skippe `RECURSIVE`).
- Mots-clés manquants : `MERGE`, `CALL`, `DO`, `SET ROLE`, `LOAD`, `pg_read_file`, `pg_ls_dir`, `pg_sleep`.
- Aucune protection DB-level (pas d'utilisateur Postgres `SELECT`-only).

**Fix** : utiliser `sqlglot` pour parser le SQL, créer un user DB readonly pour `/v1/ai/ask`.

### H2. `useMemo` deps manquantes — filtres photos cassés
**Fichier** : `app/photos/page.tsx:106`

Le `visible` memo lit `activeCamera`, `activeLocation`, `onlyGeo` mais le dep array contient seulement `[photos, activeYear, sort]`. Toggler les filtres caméra/lieu/GPS ne fait rien.

**Fix** : ajouter les 3 deps manquantes.

### H3. SSE URL build-time dans dashboard-grid
**Fichier** : `components/dashboard-grid.tsx:42-43`

`process.env.NEXT_PUBLIC_HUB_API_URL ?? 'http://localhost:8000'` — codé au build. Cassera si déployé sur autre hostname (alors que `lib/api.ts` détecte runtime, justement pour éviter ce problème).

**Fix** : exporter `getBaseUrl()` de `lib/api.ts` et l'utiliser ici.

### H4. Lightbox photos crash si `visible` shrink pendant ouvert
**Fichier** : `app/photos/page.tsx:619`

Si SWR refetch shrink le tableau pendant que le lightbox est ouvert, `photos[index]` devient `undefined` → crash sur `photo.media_id`.

**Fix** : `if (!photo) return null` au début du composant Lightbox.

### H5. API client ne gère pas 401/403/429
**Fichier** : `lib/api.ts:51-57`

Tout non-2xx → `ApiError` générique. Un 401 d'un OAuth révoqué (cas actuel B3) montre toast vague au lieu de "reconnecte tes services".

**Fix** : brancher sur status code dans `request()`.

### H6. Photo sync polling sans abort
**Fichier** : `app/photos/page.tsx:124-137`

Loop polling 10min sans cancellation si user navigue ailleurs. State setters firent sur composant unmounted.

**Fix** : `AbortController` ou `cancelled` ref.

### H7. Watchdog sans circuit breaker
**Fichier** : `hub-deploy/scripts/hub-core-watchdog.ps1:67-84`

Si Python est cassé, restart toutes les 30s à l'infini. Log file croit sans rotation.

**Fix** : max 5 essais consécutifs + log rotation.

### H8. PowerShell `$args` et `$matches` overridés
**Fichiers** : `launch-app.ps1:271`, `backup-restic.ps1:32-39`, `update-duckdns.ps1:23-30`

`$args` et `$matches` sont des variables automatiques PowerShell. Les utiliser comme variables locales casse de manière silencieuse selon scope.

**Fix** : renommer en `$cmdArgs` / `$envMatch`.

### H9. `pg_dump` mélange stdout/stderr
**Fichier** : `hub-deploy/scripts/backup-hub.ps1:103`

`docker exec ... pg_dump 2>&1 > $dumpPath` → erreurs dans le SQL. Si pg_dump fail, le restore restorera des messages d'erreur comme du SQL.

**Fix** : séparer streams + check exit code.

### H10. Backup Restic SQL non-compressé mais nommé `.sql.gz`
**Fichier** : `hub-deploy/scripts/backup-restic.ps1:146`

`gzip` n'existe pas par défaut sur Windows. Le fichier est `.sql.gz` mais en réalité non compressé. Restore par `gunzip` cassera.

**Fix** : utiliser `pg_dump -F c` (custom format binaire) ou 7-Zip.

### H11. Kill-by-regex peut tuer des process arbitraires
**Fichiers** : `launch-app.ps1:213-219`, `stop_hub.ps1:31-37`, `hub-core-watchdog.ps1:43-48`

Match `uvicorn.*src.main:app` ou `hub-core` dans la command line tue n'importe quel python qui contient ces strings (autres projets de Marc).

**Fix** : matcher sur WorkingDirectory exact + nom script.

### H12. Token Cloudflare dans `--token` argument
**Fichier** : `docker-compose.prod.yml:113`

`command: tunnel ... run --token ${CLOUDFLARE_TUNNEL_TOKEN}` → token visible dans `docker inspect`, `ps`, logs daemon Docker.

**Fix** : passer via env var `TUNNEL_TOKEN` (cloudflared le lit nativement).

### H13. PDFs sans limite de taille/pages → DoS
**Fichier** : `hub-ingest/src/parsers/desjardins_mastercard_pdf.py`, `disnat_pdf.py`

Aucun garde-fou contre PDF avec millions de pages. `for page in pdf.pages` charge tout.

**Fix** : `if len(pdf.pages) > 200: raise`.

### H14. Path traversal dans `replay.py`
**Fichier** : `hub-ingest/src/scripts/replay.py:82-84`

`for f in sorted(day_dir.iterdir())` puis `dest = target_inbox / src.name`. Si un raw_event a un nom contenant `..`, écriture hors de `target_inbox`.

**Fix** : skip si `".." in src.name or "/" in src.name`.

## 5. 🟡 MOYEN — code smells, edge cases

### Backend
- Fernet key dérivée par SHA-256 simple (pas de KDF/salt) — `src/core/crypto.py:30-31`
- Subprocess OSINT hérite tout l'env (incluant `SECRET_KEY`, OAuth secrets) — `src/api/v1/osint.py:80-100`
- `_parse_holehe_output` parse stdout texte (cassera si holehe upgrade format)
- `_get_root_folder_id._cache` sans TTL (mauvais si Marc reconnecte autre Google account)
- `Photo.user_email` hardcodé en default partout (au lieu de settings)

### Frontend
- `useEventSource` reconnect storm (5s × forever, pas d'exponential backoff)
- Calendar timezone : `parseISO` + `getHours()` cassent si Marc voyage / DST
- `LiveStatCards` lit `lastTxns?.[0]?.balance_after` comme "current balance" — pas représentatif si plusieurs comptes
- `signedAmount` retourne `0` si `debit && credit` tous null → affiche `+0,00 $` au lieu de `—`
- `searchParams` reads après OAuth toast restent en URL → reload re-fire toast

### Infra
- `init_sqlite.py 2>&1 | Out-Null` swallowe les erreurs de migration
- `hub-deploy/docker-compose.dev.yml:71-72` bind sur `0.0.0.0:8000` au lieu de `127.0.0.1:8000` (LAN-accessible)
- Pas de fallback parser pour Google Takeout 2024+ format `semanticSegments` (parser dit format A only)
- Pipelines move-on-success : 1 erreur sur 1M points → re-traitement complet
