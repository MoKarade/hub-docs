# hub-docs

Documentation française complète du Personal Data Hub.

Ce repo est volontairement séparé du code : la doc évolue à son propre rythme et tu peux la consulter sans installer le hub.

## Sommaire

- `01-vision.md` — Pourquoi ce projet, qui en bénéficie, ce qu'il n'est PAS
- `02-architecture.md` — Schémas, choix techniques, flux de données
- `03-data-model.md` — Modèles de données + invariants importants
- `04-api-contract.md` — Specs OpenAPI commentée (Phase 1+)
- `05-versioning-apps.md` — Comment cohabitent v1/v2/v3 d'une app
- `06-security.md` — Threat model, secrets, droits
- `07-runbook.md` — Que faire si X tombe en panne
- `08-rgpd.md` — Suppression de données, droits utilisateur
- `tutorials/` — Tutos pas à pas pour les actions courantes
- `decisions/` — ADR (Architecture Decision Records)

## Convention de rédaction

- En français
- Markdown standard
- Diagrammes : Mermaid (rendu natif sur GitHub)
- Pas de captures d'écran obsolètes : préférer du texte qui ne se périme pas
- ADR : 1 fichier par décision majeure, format court
